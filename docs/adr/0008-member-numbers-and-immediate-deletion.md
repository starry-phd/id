# ADR 0008：會員編號、完整顯示、立即刪除（業主 2026-11-07 決定）

## 決定
1. **會員編號**：`<國碼>-<7 碼隨機>`（例如 `886-0112342`），每位會員唯一、永久、不重用。註冊時國碼取自 Cloudflare 的 `cf-ipcountry`（IP 國家，App 不需要任何電話權限），查不到用 `886`。既有會員由每分鐘排程補發 `886-` 開頭的編號（不放在 migration，避免隨機撞號讓部署失敗）。編號用於客服售後，也是各繁星 App 在 R2 儲存會員資料的資料夾名稱（新頭像已使用；舊檔照舊）。內部主鍵仍是 UUIDv7。已刪除會員的編號進入 `retired_member_numbers`，永不再發。
2. **後台完整顯示**：會員查詢不再遮罩姓名與 Email（所有角色），改在每次開啟會員資料時寫稽核 `admin.member_viewed`；內部 UUID 在詳細頁預設收起。查詢支援關鍵字（編號／姓名／Email 片段）、狀態、登入方式、註冊國家、加入日期、Battery 剩餘範圍、只看管理人員。Battery 在另一個資料庫，範圍篩選用分頁掃描。
3. **立即刪除**：`POST /v1/me/deletion`、網頁帳號中心、Owner 後台都立即永久刪除（`deleteMemberNow`），沒有 7 天等待期。網頁與後台需輸入 `DELETE`。接著清除頭像、帳務與 Battery 資料並排入 RevenueCat 客戶刪除；Apple 權杖進撤銷佇列。舊的「待刪除」帳號仍依原排程清除（`purgeExpiredDeletions`）。
4. **法律文件**：隱私權政策與服務條款改版（`2026-11-07`），所有會員需重新同意。

## 取捨
- 不更動 `/v1` 契約結構：只改文字描述與 `status` 值（`deleted`）。回應欄位 `deletion_purge_at` 保留（值為刪除當下時間）。
- 國碼為 IP 推定，VPN 使用者可能不是實際所在國；不影響唯一性。

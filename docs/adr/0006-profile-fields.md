# 0006｜會員個人資料欄位恢復原規格

日期：2026-11-03｜狀態：已採用（業主指示）

## 背景

v2.0 規格 S-ID-08（【預設】）把會員資料縮成顯示名稱、頭像、生日、語系。業主審閱後指出與原本需求不同，要求恢復舊版《開發清單交接包》第 02 章 02.01～02.10（02.06 安麗背景屬 H-Global，維持暫停）。

## 決定

| 原編號 | 做法 |
|---|---|
| 02.01 | 姓名（`display_name`）、頭像、主要聯絡 Email（`contact_email`，會員自填；寄確認連結，確認後系統信改寄此信箱）、生日、國家（ISO 兩碼）、省／州／縣市、城市 |
| 02.02 | 手機選填，每人一組，存 E.164；本地號碼依國家補國碼（未設國家視為台灣）；不要求唯一、不做 SMS 驗證、不用於合併帳號、預設不公開 |
| 02.03 | 沿用：App 端裁切壓縮，伺服器只收小圖；沒頭像顯示姓名首字 |
| 02.04 | 生日完整保存；即時推算星座、天賦數（生日數字和在化為個位數之前的各層，例如 31）、生命靈數（最後的個位數）、九宮格（生日數字＋天賦數＋生命靈數，忽略 0；排列 3-6-9／2-5-8／1-4-7，八條連線）。公開時生日只顯示月日，推算資訊只公開星座與生命靈數（天賦數與九宮格會透露出生年）；未滿 18 歲一律不公開 |
| 02.05 | 座右銘最多 200 字；隨機提案只填入編輯框，按儲存才生效；提案文字為本專案自行撰寫，不依賴其他專案 |
| 02.07 | 帳號中心每欄有 ✏️，離開欄位自動儲存並顯示儲存中／已儲存／失敗；沒有 JavaScript 時每欄是普通表單 |
| 02.08 | 沿用 If-Match 版本號（409）；不做欄位短鎖 |
| 02.09 | 公開設定以欄位群組為單位：姓名、頭像、生日、推算資訊、地區、手機、座右銘、聯絡 Email；預設只有姓名、頭像、座右銘公開。`GET /v1/me` 附 `public_profile` 預覽其他會員看到的內容 |
| 02.10 | `profile_field_updates` 記錄每欄最後修改時間與修改者（本人／客服人員），不保存舊值 |

## 影響

- 隱私權政策改版為 `2026-11-03.2`，揭露新增欄位與公開設定；會員需重新同意一次。
- API 只有新增欄位與端點（`POST /v1/me/contact-email/verification`、`GET /v1/me/motto-suggestion`），不影響既有呼叫。
- 顯示其他會員資料的功能（例如名錄）目前沒有 App 需要，屆時只能使用 `public_profile` 的欄位。

## 必須按最新版重新審閱的 4 個差異（不能直接沿用 DEV 副本文字）

1. **07.02（DEV-A）**：主清單是「Starry 限定服務（舊『共用錢包』功能待你審核）」；DEV-A 標題是「Starry 限定與共用錢包」。**錢包並未核准**，不能因 DEV-A 舊標題而開發錢包、餘額或扣抵。
2. **08.08（DEV-C）**：主清單「實體活動票券與 **PAYUNi** 統一金流」；DEV-C 舊標題「實體活動票券與 **藍新** 金流」。**PAYUNi 是主交接包最新描述**；H-Global 目前暫停實作，不得使用舊名稱誤接供應商。
3. **12.05（DEV-I）**：主清單「**已採納**：雙獨立 Auth、雙會員 ID」；DEV-I 舊標題「重要新架構**待決**：雙獨立 Auth」。**以雙品牌完全獨立 ID 的最新核准架構為準**，但不等於每個 Auth 實作細節已核准。
4. **12.06（DEV-I）**：主清單「新案從零建立資料與資源（**舊會員遷移不適用**）」；DEV-I 舊標題「另一重要待決：新庫與舊資料處置」。已核准新案重新開發；不得將舊資料庫或舊會員遷移誤列必備功能。

此外 **P01～P10** 在九份 DEV 文件統一採簡短領域標題，而主文件採完整功能定義，因此文字不相同但編號一致。使用編號對應，**不得以字串不一致直接判定功能被刪除**。

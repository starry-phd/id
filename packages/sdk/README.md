# Starry ID minimal public health SDK (AI-4)
This is a **draft package only**. It provides a typed client for the implemented, public `GET /v1/health` liveness endpoint.
It **does not** authenticate members, expose management APIs, collect usage metrics, or prove readiness/production availability.
The cross-brand port is a no-network, permanently disabled placeholder pending owner and AI-0 Gate decisions.
No `H-Global` service or real API URL is configured.

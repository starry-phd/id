## R15 新真程式（只改 AI-1）
- \`src/round15-deletion-source-contract.ts\`：default OFF、Starry development/staging only 的**伺服器內部、唯讀**來源查驗。每次先執行由 AI-0/Privacy 控管的 \`legalDeletionProcessingApprovedNow()\`；不准時 **不讀 Auth D1**。固定 prepared \`SELECT\` 在同一 Auth DB 直接 join **已提交** \`starry_deletion_outbox\` 與當下 \`starry_members\`，並同 SQL 查所有仍未撤銷 Session 數。只有 event_id/uid/時間/型別完整、member 目前 deleted/auth_version≥2、刪帳 updated_at 與 outbox occurred_at 相同、公開 Profile 已清除、全部 Starry Session 已撤銷，才內部發出 WeakSet sealed 原始 Auth committed event。
